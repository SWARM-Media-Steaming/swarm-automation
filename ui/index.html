TL;DR

Get started in six steps

  1. — enter the GitHub repository (owner/name) and the assignee whose issues the worker may pick up, then clone the managed workspace.
  2. — enable and sign in to at least one provider (Claude, Codex, or Grok).
  3. — under the Repository page's Bots & Access tab, set up the enabled providers’ GitHub Apps so commits and reviews remain attributable.
  4. Press Save configuration (top right).
  5. — choose a pickup schedule (Continuous, Daily, Weekdays, Custom, or Manual).
  6. Press Start for the schedule, or Run now for one issue, then watch .

IN PLAIN TERMS

What is SWARM Automation?

It watches assigned GitHub issues, asks an enabled AI provider to make the change, and asks another provider to review it. The work stays on protected AI branches until you choose to move it to the human-owned branch. It runs on this Mac using your existing AI accounts.

WHEN SOMETHING IS OFF

Troubleshooting

The worker won’t start

Check the readiness list. The banner there names the first setting or sign-in that needs attention.

A provider says “Sign-in required”

Open and select Sign in on that provider’s card. Finish the provider’s login, then refresh detection in .

Nothing happens on the schedule

A Manual profile only runs on Run now. For recurring pickup choose Continuous / Daily / Weekdays / Custom in the panel, then press Start.

How do I stop everything?

Closing the window only hides the app to the menu bar — workers keep running. Use Quit and stop workers in the menu-bar menu to terminate every supervised process group.

Where are the logs and settings?

Open and select Open log folder. Settings stay in a private local file.
